# Examples

`minimal_route_trace.csv` is a small route-checkpoint file for testing the local CSV loader.

1. Open the live application or `index.html` locally.
2. Select **Load CSV files**.
3. Choose `minimal_route_trace.csv`.
4. Select the `minimal demo` model and move the time slider.

The current viewer derives its route-simplex state from `host_0` through `host_4`.
