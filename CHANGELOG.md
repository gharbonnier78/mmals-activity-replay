# Changelog

All notable changes to MMALS Activity Replay are documented here.

## [0.2.0] - 2026-06-19

### Added

- Replay Bundle v1 and `run_manifest.json` contract.
- Full, standard, and compact replay profiles.
- Hosted manifest loader and local multi-file bundle loader.
- Portable compact JSON loader and compact replay export.
- Core and route-function domain-pack descriptors.
- Run identity, provenance, and structural validation panel.
- JSON Schemas for manifests, events, compact replays, and domain packs.
- Dependency-free Python validator and compact replay builder.
- Contract unit tests and CI validation before GitHub Pages deployment.
- Compact/embed entry point.
- Compatibility manifest for the existing public MMALS v0.9 CSV files.

### Changed

- Refactored the static application into `index.html`, `assets/app.js`, and `assets/styles.css`.
- Clarified that the five-host view is a 2D barycentric projection of a higher-dimensional simplex.
- Made observed, derived, and interpolated provenance visible in run and event panels.
- Updated README, citation metadata, publishing guidance, and version labels to 0.2.0.

### Preserved

- Browser-only deployment and local file privacy.
- Legacy CSV loading.
- Training and inference/audit modes.
- Ecosystem graph, route geometry, synchronized traces, and A-to-B comparison.
- Scientific warning that visual objective lenses are not causal reruns.

### Not included

- Goal-Adaptive Control replay.
- CAL Action Gate.
- TPUT, Geometry G1, and RC2O domain packs.

## [0.1.1] - 2026-06-19

- Frozen route-function replay baseline.
- Aligned version metadata and retained one GitHub Pages workflow.
- Preserved the public v0.9 evidence and legacy CSV behavior.

## [0.1.0] - 2026-06-18

- Initial standalone route-function activity replay application.
