# Changelog

All notable changes to this project are documented here.

## [0.1.1] - 2026-06-18

### Added

- Publish-ready standalone GitHub repository.
- Self-contained browser application at `index.html`.
- GitHub Pages deployment workflow.
- MMALS v0.9 demonstration CSV exports.
- Event-level trace schema for future training and inference replays.
- User manual in PDF and LaTeX source form.
- CSV contract and scientific-fidelity documentation.
- Citation, MIT license, contribution guidance, and release metadata.

### Clarified

- Route geometry is represented on a probability simplex by default.
- Carbon is a physical metric only when a physical energy or CO2e field is logged.
- Regime-change probability is distinguished from an uncalibrated visual proxy.
- The objective selector is an analytical lens, not a counterfactual recomputation.

## [0.1.0] - 2026-06-18

- Initial standalone interactive prototype.
